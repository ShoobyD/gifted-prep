# מחוננים – תרגול

אפליקציית תרגול לקראת מבחן המחוננים של כיתה ב׳, שלב א׳.
היא מיועדת לטאבלט אנדרואיד, ואפשר להתקין אותה כאפליקציה (PWA) שעובדת גם בלי אינטרנט.

לשימוש אישי בלבד. הריפו (בתיקייה `resources/`) ומאגר השאלות בשרת כוללים את מבחני משרד החינוך ודוגמאות מאתרי הכנה, שכל הזכויות בהם שמורות.
אין לפרסם את האפליקציה או את הריפו ברבים.

## מה יש באפליקציה

- **הבנת הנקרא**: 22 קטעים: מתוך מבחנים רשמיים ודוגמאות, וגם סיפורים וקטעי מידע מקוריים. השורות ממוספרות כמו בחוברת.
- **חשבון**: 6 סוגי שאלות לפי המבחן, עם מחוללים אינסופיים ורמת קושי שמתאימה את עצמה. יש גם סבב של שאלות ממבחנים אמיתיים.
- **מבחן דמה**: מבחן 2025 האמיתי, חוברת הדוגמאות, מכון נעם, ומבחן חדש שנוצר בכל פעם. הטיימר רך והתשובות מוצגות רק בסוף.
- **כוכבים ומדבקות**, ו**אזור הורים** עם סטטיסטיקה לפי סוג שאלה, ייצוא וייבוא של ההתקדמות, והגדרת הקראה.
- **כמה משפחות וכמה ילדים**: כל משפחה נכנסת עם סיסמה משלה ורואה רק את הילדים שלה. לכל ילד התקדמות משלו, וטאבלט יכול להיות של ילד אחד או משותף לכמה ילדים.
- **הקראה בעברית** 🔊 לשאלות חשבון ולהסברים.

החומרים הגולמיים (PDF, דוגמאות וסיכום המחקר) נמצאים ב-[`resources/`](resources/README.md).

## פיתוח

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # בדיקות: מחוללים, מאגר, התקדמות, הקראה
npm run build      # בדיקת טיפוסים ו-build לתיקייה dist/
npm run serve      # הגשת ה-build על פורט 4173, גם ברשת המקומית
```

### שרת (Cloudflare Pages Functions + D1)

הכול נשמר במסד נתונים D1, והמבנה מוגדר ב-`schema.sql`:
- `families` ו-`children`: המשפחות והילדים.
- `progress`: ההתקדמות של כל ילד, שורה לכל ילד.
- `bank_items` ו-`bank_history`: מאגר השאלות וכל הגרסאות שלו.

ה-API נמצא ב-`functions/api/`:
- `progress?child=<id>`: ההתקדמות של ילד. בלי ילד, הבקשה הולכת לילד הראשון במשפחה.
- `children`: הילדים של המשפחה המחוברת.
- `bank`: המאגר. כל משפחה קוראת אותו, ורק משפחת המנהל כותבת בו.
- `admin/families`: ניהול המשפחות, למנהל בלבד.

כל האתר נעול בסיסמה (`functions/_middleware.ts`). מי שלא מחובר מקבל רק דף כניסה קטן, בלי קוד האפליקציה ובלי התוכן.
פתוחים רק ה-manifest, האייקונים ו-`robots.txt`, כי כרום טוען אותם בלי עוגייה בזמן התקנה.
בדף הכניסה מקלידים רק סיסמה. הסיסמה לבדה קובעת לאיזו משפחה נכנסים, ולכן לכל משפחה סיסמה אחרת.
ההתחברות נשמרת שנה. שני סודות שמורים מחוץ לקוד:

- `SESSION_SECRET`: חותם את עוגיית ההתחברות ומצפין את סיסמאות המשפחות במסד. **החלפתו מנתקת את כולם ומבטלת את כל סיסמאות המשפחות**, ואז צריך לקבוע אותן מחדש.
- `FAMILY_PASSWORD`: הסיסמה של משפחת המנהל, רק עד שהיא קובעת סיסמה משלה במסך "משפחות".

איפה הם נשמרים:
- **מקומית:** בקובץ `.dev.vars`, שלא נכנס ל-git. מעתיקים אותו מ-`.dev.vars.example` וממלאים.
- **בענן:** כמשתנים מוצפנים בהגדרות הפרויקט ב-Cloudflare Pages.

```bash
npm run db:schema:local   # פעם אחת: יוצר את המסד המקומי (בתיקייה .wrangler/)
npm run db:bootstrap:local -- --family="משפחה מקומית" --child="ילד"   # פעם אחת: משפחת המנהל והילד הראשון
npm run db:export && npm run db:import:local -- backups/bank-<תאריך>.json   # פעם אחת: עותק של המאגר האמיתי
npm run dev:api           # build ואז שרת מלא על http://localhost:8788, כולל ה-API
npm run test:api          # בחלון נוסף: בדיקת ה-API מקצה לקצה מול השרת המקומי
```

`dev:api` מגיש את ה-build. כדי לראות שינויים בקוד צריך להריץ אותו מחדש.
ב-Windows, עצירה של wrangler משאירה לפעמים תהליכי `workerd.exe` ברקע, שממשיכים לתפוס את פורט 8788 ולענות עם קוד ישן.
אם הבדיקות נכשלות בלי סיבה, סוגרים אותם במנהל המשימות.
בלי השרת, `npm run dev` עדיין עובד כרגיל.

> אם `npm install` נכשל עם `Cannot read properties of null (reading 'edgesOut')`, זה באג של npm 10.9.2.
> אפשר לעקוף אותו עם `npx npm@11 install`.

## פריסה (Cloudflare Pages)

האתר רץ ב-Cloudflare Pages ומחובר לריפו ב-GitHub (חייב להישאר **פרטי**). כל push ל-`main` נבנה ועולה אוטומטית.

### הקמה חד-פעמית

1. **התחברות של wrangler לחשבון Cloudflare** (בטרמינל אינטראקטיבי):
   ```bash
   npx wrangler login
   ```
2. **יצירת מסד הנתונים בענן:**
   ```bash
   npx wrangler d1 create gifted-prep
   ```
   מעתיקים את ה-`database_id` שמודפס אל `wrangler.toml` במקום האפסים. אחר כך יוצרים את הטבלאות, את משפחת המנהל עם הילד הראשון, וטוענים את מאגר השאלות מקובץ גיבוי:
   ```bash
   npm run db:schema
   npm run db:bootstrap -- --family="שם המשפחה" --child="שם הילד"
   npm run db:import -- backups/bank-<תאריך>.json
   ```
3. **יצירת פרויקט Pages:** בלוח הבקרה של Cloudflare ← Workers & Pages ← Create ← Pages ← Connect to Git ← בוחרים את `ShoobyD/gifted-prep`.
   - Project name: `gifted-prep-il` (הכתובת: `gifted-prep-il.pages.dev`. השם `gifted-prep` תפוס ב-pages.dev). בוחרים בלשונית **Pages** ולא Workers
   - Production branch: `main`
   - Build command: `npm run build`
   - Build output directory: `dist`
4. **סודות:** בפרויקט ← Settings ← Variables and Secrets, מוסיפים שני משתנים מסוג **Secret** (Production):
   - `FAMILY_PASSWORD`: הסיסמה הראשונה של משפחת המנהל.
   - `SESSION_SECRET`: מחרוזת אקראית ארוכה. אפשר לייצר אחת כך:
     ```bash
     node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
     ```
   סודות נכנסים לתוקף רק בפריסה הבאה (Deployments ← Retry deployment, או push חדש).

## התקנה על הטאבלט

1. בכרום בטאבלט פותחים את `https://gifted-prep-il.pages.dev` ומתחברים עם הסיסמה של המשפחה.
2. בוחרים **"הטאבלט של הילד"**. במשפחה עם כמה ילדים בוחרים גם **של מי הטאבלט**:
   - **של ילד אחד:** האפליקציה נפתחת ישר אצלו.
   - **משותף:** בכל פתיחה, ובחזרה לאפליקציה אחרי יותר מ-5 דקות, מופיע המסך **"מי מתרגל עכשיו?"** עם השם והציור של כל ילד. במסך הבית יש גם כפתור החלפה.
3. בתפריט ⋮ בוחרים **הוספה למסך הבית** (או **התקנת האפליקציה**).

מאותו רגע האפליקציה עובדת גם בלי אינטרנט. ההתקדמות של כל ילד נשמרת בטאבלט ומגובה בשרת כשיש חיבור.
את סוג הטאבלט אפשר לשנות בתפריט הנסתר: לחיצה ארוכה על הכותרת, ואז תרגיל הכפל.

## מעקב מהטלפון ומהמחשב

פותחים את `https://gifted-prep-il.pages.dev`, מתחברים ובוחרים **"מכשיר של הורה"**.
מוצגת ההתקדמות האחרונה שהטאבלט גיבה. אפשר גם להוסיף למסך הבית.

- **כמה ילדים:** בראש לשוניות "מעקב" ו"הגדרות" בוחרים את הילד.
- **הוספה ועריכה של ילדים:** בלשונית **⚙️ הגדרות**, בכרטיס "הילדים": שם, ציור, ומחיקה (ההתקדמות נמחקת יחד עם הילד).

## ניהול משפחות (למנהל)

במכשיר הורה של משפחת המנהל, בלשונית **👪 משפחות**:

- **משפחה חדשה:** שם, סיסמה, ואם רוצים גם הילד הראשון. מוצעת סיסמה אקראית שקל להקליד. אחרי השמירה הסיסמה מוצגת פעם אחת עם כפתור העתקה, כדי להעביר אותה למשפחה.
- **סיסמה חדשה ושינוי שם:** לכל משפחה, גם לשלכם. אחרי שקובעים לעצמכם סיסמה, `FAMILY_PASSWORD` מפסיקה לעבוד. מכשירים שכבר מחוברים נשארים מחוברים.
- **מחיקה:** מוחקת את המשפחה, את הילדים שלה ואת ההתקדמות שלהם, והמכשירים שלה מתנתקים. את משפחת המנהל אי אפשר למחוק.

השרת שומר רק את הסיסמה המוצפנת. סיסמה שנשכחה מחליפים, ולא מציגים.
המאגר משותף לכל המשפחות, ורק משפחת המנהל רואה את לשונית המאגר ויכולה לערוך.

## ניהול מאגר השאלות

במכשיר הורה של משפחת המנהל, בלשונית **📚 מאגר שאלות**:

- **עיון וחיפוש:** קטעי הקריאה ושאלות החשבון הקבועות, כולל המוסתרים. החיפוש מתעלם מניקוד. אפשר לסנן לפי מקור, לפי סוג שאלה ולפי מצב (מוצגים / מוסתרים / נערכו / נוספו).
- **תצוגה:** הפריט כמו שהילד רואה אותו, עם התשובה הנכונה וההסבר.
- **הסתרה:** פריט מוסתר לא מופיע בתרגול ובמבחן החדש. המבחנים הרשמיים שומרים על המבנה שלהם ולא משמיטים פריטים.
- **עריכה:** נוסח, ניקוד, שורות הקטע, תשובות, הסבר ומקור. לפני שמירה רצה אותה בדיקה שרצה בייצוא ובייבוא של המאגר. למשל, תשובה מספרית נבדקת מול התרגיל, ומספרי שורות שמוזכרים בשאלות חייבים להתקיים בקטע. כל שמירה נשמרת כגרסה, ובכפתור **"גרסאות קודמות"** אפשר לטעון גרסה ישנה ולשמור אותה שוב.
- **הוספה ומחיקה:** קטעים חדשים עם שאלות, ושאלות חשבון חדשות. אפשר למחוק כל פריט שאינו חלק ממבחן רשמי (פריט כזה אפשר רק להסתיר).

המאגר כולו נשמר בשרת (טבלאות `bank_items` ו-`bank_history` ב-D1), ולא בקוד.
כל המכשירים מקבלים אותו בפתיחה ובחזרה לאפליקציה, ושומרים עותק לעבודה בלי אינטרנט.
מכשיר שעוד לא טען את המאגר אף פעם (למשל טאבלט חדש שלא היה מחובר) מציג רק את שאלות החשבון שנוצרות אוטומטית.
שאלות החשבון שהמחוללים יוצרים אוטומטית לא נשמרות, ולכן אינן במאגר.

## עדכון גרסה

push ל-`main` בונה ומעלה גרסה חדשה. בפתיחה הבאה של האפליקציה (כשיש אינטרנט) מופיע הבאנר **"יש גרסה חדשה 🎁"**, ולוחצים **עדכון**.
האפליקציה לא מתעדכנת מעצמה באמצע מבחן, וההתקדמות נשמרת.

## גיבוי ושחזור

- **מאגר השאלות:** `npm run db:export` שומר את כולו לקובץ `backups/bank-<תאריך>.json` (התיקייה לא נכנסת ל-git). `npm run db:import -- <קובץ>` טוען קובץ כזה למסד, ומוסיף רק פריטים שחסרים בו. שתי הפקודות בודקות את התוכן, ו-`:local` בסוף השם עובד על המסד המקומי. כדי להחזיר גרסה ישנה של פריט קיים משתמשים ב"גרסאות קודמות" באפליקציה.
- ההתקדמות של כל ילד מגובה בשרת אוטומטית. בטאבלט חדש, אחרי התחברות ובחירת הילד, היא נטענת מהשרת.
- אפשר גם לייצא לקובץ, לייבא ולאפס, לכל ילד בנפרד: במכשיר הורה, בלשונית **⚙️ הגדרות**. הפעולות מגיעות לטאבלט בפתיחה הבאה שלו, וגוברות גם על שינויים שעוד לא נשלחו ממנו.
