# מחוננים – תרגול

אפליקציית תרגול לקראת מבחן המחוננים של כיתה ב׳, שלב א׳.
היא מיועדת לטאבלט אנדרואיד, ואפשר להתקין אותה כאפליקציה (PWA) שעובדת גם בלי אינטרנט.

לשימוש אישי בלבד. הריפו כולל את מבחני משרד החינוך ודוגמאות מאתרי הכנה, שכל הזכויות בהם שמורות.
אין לפרסם את האפליקציה או את הריפו ברבים.

## מה יש באפליקציה

- **הבנת הנקרא**: 22 קטעים: מתוך מבחנים רשמיים ודוגמאות, וגם סיפורים וקטעי מידע מקוריים. השורות ממוספרות כמו בחוברת.
- **חשבון**: 6 סוגי שאלות לפי המבחן, עם מחוללים אינסופיים ורמת קושי שמתאימה את עצמה. יש גם סבב של שאלות ממבחנים אמיתיים.
- **מבחן דמה**: מבחן 2025 האמיתי, חוברת הדוגמאות, מכון נעם, ומבחן חדש שנוצר בכל פעם. הטיימר רך והתשובות מוצגות רק בסוף.
- **כוכבים ומדבקות**, ו**אזור הורים** עם סטטיסטיקה לפי סוג שאלה, ייצוא וייבוא של ההתקדמות, והגדרת הקראה.
- **הקראה בעברית** 🔊 לשאלות חשבון ולהסברים.

החומרים הגולמיים (PDF, דוגמאות וסיכום המחקר) נמצאים ב-[`resources/`](resources/README.md).

## פיתוח

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # בדיקות: מחוללים, תוכן, התקדמות, הקראה
npm run build      # בדיקת טיפוסים ו-build לתיקייה dist/
npm run serve      # הגשת ה-build על פורט 4173, גם ברשת המקומית
```

> אם `npm install` נכשל עם `Cannot read properties of null (reading 'edgesOut')`, זה באג של npm 10.9.2.
> אפשר לעקוף אותו עם `npx npm@11 install`.

## התקנה על הטאבלט

כדי שהאפליקציה תעבוד בלי אינטרנט צריך service worker.
דפדפנים מאפשרים service worker רק בכתובת `localhost` או ב-HTTPS, ולא בכתובת רשת כמו `http://192.168.1.20:4173`.
לכן יש שלוש דרכים להתקין.

בכל הדרכים מתחילים במחשב: `npm run build` ואחר כך `npm run serve`.

### דרך א׳ (מומלצת): כבל USB והעברת פורטים בכרום

בשיטה הזו הטאבלט ניגש ל-`localhost`, ולכן הכתובת קבועה וההתקדמות לא הולכת לאיבוד.

1. בטאבלט מפעילים את **אפשרויות המפתחים**: הגדרות ← מידע על הטאבלט ← לוחצים 7 פעמים על "מספר Build".
2. בתוך אפשרויות המפתחים מפעילים את **ניפוי באגים ב-USB**.
3. מחברים את הטאבלט למחשב בכבל ומאשרים בטאבלט את חלון ההרשאה.
4. בכרום שבמחשב פותחים את `chrome://inspect/#devices`.
   לוחצים על **Port forwarding**, מוסיפים `4173` ← `localhost:4173`, ומסמנים את **Enable port forwarding**.
5. בכרום שבטאבלט פותחים את `http://localhost:4173`, ובתפריט ⋮ בוחרים **הוספה למסך הבית** (או **התקנת האפליקציה**).
6. אחרי שהאפליקציה נטענת פעם אחת היא עובדת גם בלי הכבל ובלי אינטרנט.

### דרך ב׳: ברשת Wi-Fi עם דגל בכרום

השיטה הזו לא דורשת כבל.
**שימו לב:** ההתקדמות קשורה לכתובת. אם כתובת ה-IP של המחשב תשתנה, האפליקציה תיפתח ריקה.
כדי למנוע את זה מקבעים את ה-IP של המחשב בראוטר, או מייצאים את ההתקדמות לפני שינוי.

1. מוצאים את כתובת המחשב ברשת. `npm run serve` מדפיס אותה כ-`Network: http://192.168.x.x:4173`.
2. בכרום שבטאבלט פותחים את `chrome://flags/#unsafely-treat-insecure-origin-as-secure`.
3. מוסיפים את הכתובת (למשל `http://192.168.1.20:4173`), בוחרים **Enabled**, ולוחצים **Relaunch**.
4. פותחים את הכתובת ומתקינים כמו בדרך א׳ (סעיף 5).

### דרך ג׳: אחסון פרטי ב-HTTPS

אפשר להעלות את `dist/` לשירות כמו Cloudflare Pages או Netlify. הם מספקים HTTPS, ומשם מתקינים מהטאבלט בלי הכנות.
אבל אז החומר המוגן נמצא ברשת. לכן מומלץ להגן על הכתובת בסיסמה, למשל עם Cloudflare Access (חינמי לשימוש קטן) או בתוכנית בתשלום של Netlify.
בשום מקרה לא כדאי לפרסם את האפליקציה בכתובת ציבורית פתוחה.

### עדכון גרסה

מריצים שוב `npm run build` ו-`npm run serve` ופותחים את האפליקציה בטאבלט כשהיא מחוברת: בדרך א׳ דרך הכבל, בדרך ב׳ ברשת.
מופיע הבאנר **"יש גרסה חדשה 🎁"**, ולוחצים **עדכון**.
האפליקציה לא מתעדכנת מעצמה באמצע מבחן, וההתקדמות נשמרת.

### גיבוי ההתקדמות

ההתקדמות נשמרת רק בדפדפן של הטאבלט.
מדי פעם כדאי להיכנס לאזור ההורים ← הגדרות ← **ייצוא לקובץ**.
